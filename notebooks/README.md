# Notebook implementation summary

The original implementation notebooks are withheld from this public repository because they contain course-specific collection paths, relevance labels, and setup material.

The work implemented these genuine experiment components:

- A custom BM25 baseline and parameter search for biomedical retrieval.
- A BERT cross-encoder reranker for the top lexical candidates.
- BM25, DPR, and TILDEv2 retrieval comparisons for a web-passage sample.
- A TinyLlama-based retrieval-augmented generation experiment.

Recorded historical metrics and important constraints are documented in the root README. Datasets, qrels, indexes, model weights, run files, and generated text are not included.
